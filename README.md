# Rivian Spotter

An independent map and directory of Rivian Spaces, Demo Centers, Service Centers and Outposts across the US and Canada.

## Run locally

Requires Node 22 or newer.

```sh
npm ci
npm test
npm run dev
```

Open http://127.0.0.1:8765. The development server serves the exact `dist` release, not the repository root. Run `npm run build` and reload after editing.

## Source of truth

- `data/locations.json`: canonical location facts, evidence, confidence, timestamps and historical ID aliases.
- `scripts/refresh-locations.cjs`: repeatable official-directory reconciliation. See [location data](docs/LOCATION_DATA.md) before a refresh.
- `scripts/generate-data.cjs`: deterministic browser bundle.
- `scripts/build-pages.cjs`: crawlable destination, region and information pages.
- `index.html`, `css/style.css`, `js/app.js`, `js/map.js`, `js/location-model.js`, `js/components.js`: explorer and shared interface.
- Root About/Contact/Saved/Updates/Stats HTML is generated by the build; edit its templates.

Public visitors do not need an account. Saved places stay on-device. Correction forms prepare an email draft; they do not submit to a backend. Mapbox uses the existing public read token in `js/config.js`; configure its permitted origins in Mapbox for production.

## Delivery

GitHub Actions runs behavioral tests, a static build and a production dependency audit. Successful pushes to `main` publish the explicit `dist` artifact to GitHub Pages. Pull requests run checks without publishing.

The obsolete PHP/VPS administration path is retired. No repository write credentials belong in public JavaScript, environment files or browser storage. `/admin`, `/admin/`, and the legacy admin URLs route directly to GitHub’s authenticated inventory editor. No maintenance interface is hosted publicly.
