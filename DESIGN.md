# RivianSpotter design system

Approved direction: map-first explorer with warm off-white, charcoal, forest, and a restrained yellow accent, following the Code to Adventure refresh's clarity and quiet confidence.

Scene: an owner checks a place on a phone in daylight before leaving, then returns to the same interface on a laptop at home. Light surfaces lead; a deliberate system-aware dark theme supports nighttime use.

Use one system sans family, bold compact headings, 16px body text, and readable secondary text. Use a 4px spacing scale. Desktop has a compact horizontal header, an approximately 400px search/results column, and a generous map. Location details occupy a separate sheet; on phones use real Map/List modes with a reachable search and bottom detail sheet. Results are rows separated by thin rules. Selected rows use a full subtle background and outline.

Colors use semantic OKLCH tokens. Primary actions are forest with warm-white text; bright yellow uses charcoal text. Category colors retain consistent meanings across markers, rows, and legends; clusters are neutral. Motion is short, purposeful, and disabled under reduced-motion preference.

Shared controls have 44px targets, clear focus, pressed/expanded states, and plain labels. Unknown information remains unknown. Every destination page includes source, verification status, and correction access.
